Privacy Center

What biometric data SmartAttend AI stores, why, and how to remove it.

What is stored

When a student is enrolled, a numeric face embedding — a list of numbers derived mathematically from their face, not a photo — is generated and stored in a dedicated face_profiles collection, separate from ordinary student records. The original camera frame is never saved.

Why it's stored

Solely to compare against future camera frames during attendance recognition. It is never used for any other purpose.

Who can access it

No API response ever includes embedding data — this is enforced at the schema level (there is no "public" version of the face profile model), not by convention. Only the enrollment and recognition services touch it internally.

Liveness verification

Liveness checks use a practical, MVP-level head-turn challenge. This is not certified anti-spoofing and will not withstand a sophisticated presentation attack — see the technical documentation for full details.

Delete a student's face enrollment

Permanently removes the stored biometric embedding for a student. Their student record and attendance history are not affected — only future recognition stops working for them until re-enrolled.
